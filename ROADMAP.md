# Roadmap

This is a focused five-day validation plan, not a production release schedule.

| Day | Goal |
| --- | --- |
| Day 1 | Engineering initialization: repository, safety rules, product and technical baseline. |
| Day 2 | Technical validation of career-ops, OpenWorker, and experimental Liepin MCP boundaries. |
| Day 3 | V0 core Career Agent: Career Interview, Career Profile, recruiter rubric, manual Job evaluation, and explanation. |
| Day 4 | V1 Alpha: improve the usable local experience and test with early users. |
| Day 5 | V2 Desktop Alpha: validate a minimal desktop technical proof, not a production release. |

Each day may reduce scope if a prior validation is incomplete. Platform integrations, automatic application, large-scale crawling, cloud services, and production distribution are outside this five-day plan.
